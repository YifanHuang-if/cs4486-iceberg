## 2. The `inc_angle` structure (this is what top teams exploited)

`inc_angle` behaves like a satellite-pass identifier. Measured on the 1,471
labelled rows with an angle:

- 878 distinct angles; 581 pure-ship, 291 pure-iceberg, **6 mixed** (17 rows).
- 1,454 of 1,471 rows (98.9%) sit in a pure angle group.

Leave-one-out check (`src/v2/angle_fusion.py`, each row's prior estimated from the
*other* rows of its group): 810 training rows have a same-angle mate; for the 394
rows whose LOO prior confidence is >= 0.9 the label is recovered **394/394 = 100%**.
Mean LOO entropy over those rows is 0.167 nats.

Test coverage: of the 3,424 real test rows, **1,950 (57.0%)** have an exact angle
match in train (1,424 pure-iceberg, 512 pure-ship, 14 mixed). Purity of the
matched training groups is 98.5%.

Why this matters: if 57% of scored rows can be predicted from the angle group at
roughly 0.03 log loss, the remaining 43% only needs an image model around 0.12
for a total near 0.07. Modelled score:

```
total = 0.57 * loss_matched + 0.43 * loss_residual
```

The score is dominated by the quality of the angle layer and by clip choice, not
by squeezing another 0.01 out of the CNN.

## 3. Validation design

Two splits, both saved as `id,fold,label,angle_missing`:

- `data/splits/folds.csv` - the frozen random stratified split (seed 42,
  stratified on label x angle_missing). Used for comparability with the earlier
  work and for the course's "unified 5-fold CV" requirement.
- `work/splits/folds_angle_grouped.csv` - generated by `src/v2/folds_grouped.py`:
  exact angle groups are never split (0 groups crossing folds), sizes
  321/321/321/321/320. This is the honest estimate of model quality, because the
  random split lets same-angle rows sit on both sides.

Augmentation happens inside the training fold only; no augmented copy is ever
created before the split.

## 4. Models

`src/v2/model.py` - small radar CNNs (0.35M-0.95M parameters): 3x3 stem, four
squeeze-excite residual blocks, GeM-style mean+max pooling, plus a 15-column
metadata branch (angle, missing flag, per-band mean/std/percentiles/min/max,
cross-channel correlation). Per-image ("local") standardisation by default.
Augmentation: dihedral flips, rotation up to +-22.5 deg, scale 0.9-1.1, shift
+-10%, Gaussian noise. Test-time augmentation: the 8 dihedral views.

## 5. Submission design (`src/v2/submit.py`)

1. Blend CNN folds/seeds in logit space (`src/v2/blend.py`).
2. Estimate an angle-group prior with shrinkage `alpha`, tuned by leave-one-out
   on training rows only.
3. Fuse in log-odds: `logit(p) = w * logit(model) + logit(prior)` for rows whose
   angle occurs in train.
4. Clip to `[1e-3, 1-1e-3]`; rows without a matching angle keep the model value.

## 6. Results

### 6.1 Image model (random 5-fold, frozen split)

| Model | Settings | OOF log loss |
|---|---|---|
| `f0_fast_s0` | 4 residual blocks, stride-2 stem, 954k params, 50 epochs, local normalisation, dihedral+affine augmentation, 8-view TTA | **0.25381** (Platt 0.25006) |
| `x1_small_gnoaug` fold 0 | full-resolution, global normalisation, no augmentation | 0.17463 plain / 0.24294 TTA |
| `x2_small_aug` fold 0 | full-resolution, local normalisation, augmentation, early stop at 16 | 0.28766 TTA |
| previous session, single CNN | 93k params + metadata | 0.1943-0.1996 |
| previous session, ensemble + transductive pooling | - | 0.13136 (optimistic) |

Lesson recorded from these runs: early stopping fights a cosine schedule (x2 stopped
at epoch 16 with the learning rate still high), and TTA only helps models trained
with the matching augmentation (x1 got worse with TTA).

### 6.2 Angle layer (leave-one-out on training rows)

| Scheme | Coverage | Loss on covered rows | Overall OOF |
|---|---|---|---|
| model only (`f0_fast_s0`) | - | 0.2693 | 0.25006 |
| exact-angle prior only | 57% of real test rows | 0.2061 | - |
| exact + Gaussian kernel (sigma 0.02, alpha 0.1) fused at weight 0.6 | **91.3%** of train rows, 96.8% of real test rows | 0.1284 | **0.12109** |

The fused 0.12109 uses no test labels: the prior comes from training labels, the
model probability comes from held-out folds, and the fusion parameters were tuned
by leave-one-out. Rows without any nearby training angle are easy (0.0436), so the
scored population is dominated by covered rows.

Score decomposition (`work/leak/decomposition.json`): to reach an official 0.083
the covered-row loss has to fall from 0.128 to about 0.086, which is a statement
about the image model, not about the angle layer.

### 6.3 Leakage checks that came back negative

- 5,000 machine-generated test rows are **not** copies of training images (max
  flip-invariant thumbnail cosine 0.61) nor of real test rows (0.68).
- No image-level duplicate leak: only 4 real test rows exceed 0.99 similarity to a
  training image, and pixel-wise comparison shows 6.6-9.6 dB differences, i.e.
  similar scenes, not copies.
- The only exploitable structure is `inc_angle`.

### 6.4 Submission

`work/submissions/final_fast_s0.csv`: 8,424 rows, ids in sample-submission order,
values in [0.001, 0.999], validated by `src/v2/verify.py`. This is the fused
prediction of the 0.2538 model; it is superseded when the next ensemble lands.
