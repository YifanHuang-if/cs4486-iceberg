- 如老师提供统一5折，正式结果使用该划分；自行划分的结果只作为补充。

## 候选划分

建议将随机分层5折作为参照，将角度分组5折作为更严格的关联样本敏感性分析。是否把分组方案作为主结果，由课程规则和小组讨论确定。

| 项目 | 随机分层参照 | 角度分组候选 |
|---|---|---|
| 方法 | StratifiedKFold | StratifiedGroupKFold |
| 折数 | 5 | 5 |
| 打乱 / 种子 | shuffle=True, random_state=42 | shuffle=True, random_state=42 |
| 已知角度 | 仅按标签分层 | 精确相同数值角度的样本同组，不按标签拆组 |
| 缺失角度 | 按标签参与分层 | 每个未知来源样本先设独立组；不能把全部缺失角度视为同一场景 |
| 完全重复图像 | 如发现，改为不拆散重复组的划分 | 相同图像指纹约束同折，必要时合并相关角度组 |

42是预先指定的起点，不是搜索出来的最佳种子。固定并记录scikit-learn版本、输入ID排序和生成方式；不同版本可能给出不同划分。

当前训练集有217个重复角度组，211组标签单一、6组标签混合。保留混合标签组，不可为了好分数拆开。入射角只是关联来源的代理，不是真实采集场景ID；精确角度分组不能识别不同角度的同源图像，也不能保证没有其他关联。

近似图像排查尚未完成，应在冻结划分前检查。近似匹配只能作为人工复核候选，不应未经验证自动合并大量样本。若之后确实新增同组约束，需要记录划分版本，并重跑对比实验。

## 冻结划分时保存

- `data/splits/folds_<scheme>_v1.csv`：每个训练样本的 `id,fold`，每个ID恰好出现一次。
- 分组方案另存组定义和生成配置；不把标签加入group key。
- 保存数据指纹、随机种子、库版本、划分文件SHA-256和Git提交号。
- 输出每折样本数、两类数量、缺失角度数，检查样本/组不跨折，且每折两类都存在。
- 所有对比模型复用同一文件，不按模型表现更换划分。

这些文件名是后续交付约定，当前文件尚未生成。

## 每折的训练边界

只用该折训练部分计算通道标准化参数、角度填补值和角度标准化参数。两个图像通道同步增强，随机增强只作用于训练样本。ID和完整角度组信息用于划分检查，不作为记忆标签的查表输入。

133条缺失角度记录全部是船，但测试集没有缺失角度。不要写死“缺失即船”规则。若使用缺失标记，要做有/无该标记的对照，并报告两个子集的样本数及Log Loss。

## 评估约定

- 主要指标是未加权的二分类Log Loss，输出应为冰山概率。
- 每个样本只接受未用该样本训练的模型预测，组成OOF概率。
- 报告每折分数、各折均值和标准差，以及拼接所有OOF后的Log Loss。均值与整体OOF分数须标注清楚，折大小不等时二者不一定相同。
- 极端概率的数值裁剪规则与库版本需固定并披露，不事后选择最有利的裁剪阈值。
- Early stopping和超参数选择会使用验证折，因此调参后的CV成绩是开发估计，不应称作完全独立、无偏的最终测试。
- 训练集集成评分只平均各方案的OOF预测；测试集推理才可以平均所有折模型的测试预测。
